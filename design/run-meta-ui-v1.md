톤: 노을 구장 · 다크 네이비 #081329 · 크림 #F7F3E8 / #FFE09A · 코랄 #FF986E · 특수 퍼플 #C3A4FF

## A. 시작 화면 — 장착 칭호 + 도감 진입

### 레이아웃 (위→아래)
1. 기존 `menu-art` (희동이 도발 컷) 유지
2. eyebrow / 타이틀 / 서브 카피 유지
3. **NEW · 장착 칭호 칩** (타이틀 바로 아래, 서브 위)
4. rules / 나의 최고 기록
5. **NEW · 「오늘의 승부」 카드** (기록 블록과 CTA 사이)
6. 랭킹 버튼 · 플레이 CTA · 인트로 다시보기

### 장착 칭호 칩
- 위치: `h1` 아래 8px, 가로 중앙
- 형태: pill `height 32` · `border-radius 999` · `padding 0 14`
- 기본(미장착): border `#7399BB55` · bg `#07172B` · 텍스트 `#AABED8` · 카피 `칭호 없음 · 도감에서 장착`
- 장착 시: border `#FFE09A88` · bg `#1A2A12` 아님 → `#142038` + 왼쪽 작은 아이콘(트로피/불꽃) · 텍스트 `#FFE09A` · 카피 `「첫 퍼펙트」` (따옴표 포함, 최대 12자)
- 탭 영역: 칩 전체가 도감 진입 (별도 버튼 최소화)
- 우측 보조: 칩 옆 또는 칩 안에 `›` 16px `#96C2F7`

### 도감 진입 (대안 배치, 권장 = 칩 탭)
- 권장: 장착 칩 탭 → 도감
- 보조: 상단 `controls`에 원형 버튼 `칭` (기존 ♪ / Ⅱ 옆, 44×44) — 사운드 왼쪽
- 아이콘: 방패+별 실루엣, stroke `#E8F2FF`, 잠금 수 뱃지(코랄 점)는 신규 해금 있을 때만

### 카피
- 칩 미장착: `칭호 없음 · 탭해서 고르기`
- 칩 장착: `장착 중 · 「불꽃 회피왕」`
- 원형 버튼 aria: `칭호 도감`

## B. 칭호 도감 패널/모달

### 컨테이너
- 기존 `.ranking-dialog` 패턴 재사용: `width min(94vw,460)` · `max-height 85dvh` · bg `#0B1E35` · border `#7897B8` · radius `16` · padding `18`
- 헤딩: 좌 `칭호 도감` 20px · 우 `닫기`
- 서브: `해금 N / 전체 M · 장착은 치장만 (효과 없음)` 12px `#BCCDE2`

### 그리드
- 2열 카드 그리드 `gap 8`
- 카드: `min-height 88` · radius `10` · border `#7195BD66` · bg `#102744` · padding `12` · text-align left

### 상태 3종
1. **잠금**
   - 아이콘: 자물쇠 · 필터 grayscale · opacity `.55`
   - 타이틀 `#7A8FA8` `???`
   - 조건 한 줄 `#A9BDD6` 예: `첫 PERFECT 1회`
   - 탭 불가(또는 탭 시 토스트 `아직 잠겨 있어요`)

2. **해금·미장착**
   - 아이콘 풀컬러 (크림/코랄/퍼플 중 칭호 테마)
   - 타이틀 `#FFE2A1` 볼드 14
   - 조건 달성 문구 `#A9BDD6` 예: `달성 · 첫 PERFECT`
   - CTA 작은 버튼 또는 카드 탭: `장착` — border `#FFE09A55` · text `#FFE09A`

3. **장착 중**
   - 카드 border `#FFE09A` · 은은한 glow `0 0 12px #FFE09A33`
   - 우상단 뱃지 `장착` 10px · bg `#FFE09A` · color `#10233D`
   - CTA: `해제` (secondary)

### 초기 칭호 예시 (아이콘·카피)

## C. 「오늘의 승부」 + 랭킹 「오늘」 탭

### C-1. 시작 화면 카드
- 위치: 나의 최고 기록 아래, 랭킹/플레이 위
- 카드: radius `12` · border `#6087CA88` · bg `linear-gradient(145deg,#122B52F7,#080F25FC)` · padding `14 14 12`
- 헤더 한 줄: 좌 `TODAY'S MATCH` eyebrow 11px `#96C2F7` · 우 `시드 · 09.13` 11px `#AABED8` (날짜는 로컬)
- 타이틀: `오늘의 승부` 16px `#F7F3E8` italic
- 목표 줄: `목표 · PERFECT 3회` 또는 `스테이지 2 도달` — `#FFE09A`
- 보상 칩: `보상 · 「일일 타자」 칭호` 또는 `포인트 +10` — 작은 pill `#1A2740` / text `#C3A4FF`
- 상태
  - 미클리어: 버튼 `오늘 한 판` full-width · primary 그라데이션 `#416EFF→#775CFF` · white
  - 클리어: 버튼 disabled `오늘 클리어 ✓` · opacity `.75` · 텍스트 `#9BFFE6`
- 보조 텍스트: `매일 자정(KST) 시드 갱신 · 랭킹 「오늘」에 기록` 11px `#AABED8`

### C-2. 랭킹 다이얼로그 탭
- `ranking-heading` 아래 탭바 추가 (h2는 `친구들과 기록 대결` 유지)
- 탭 2개: `전체` | `오늘`
- 탭 UI: underline / pill 중 **세그먼트** 권장
  - 컨테이너: bg `#07172B` · radius `8` · padding `3` · 2등분
  - 활성: bg `#173453` · text `#FFE09A` · border `#FFE09A44`
  - 비활성: text `#AABED8`
- 「오늘」 테이블 컬럼: `순위 | 닉네임 | 목표 | PERFECT` (또는 목표 타입에 맞게 `도달`)
- 빈 상태: `아직 오늘의 기록이 없어요. 한 판 뛰고 이름을 남겨 보세요.`
- 서브카피 교체: 전체=`도달 스테이지순 · 동점이면 PERFECT순` / 오늘=`오늘 시드 기준 · 목표 달성자만`

### C-3. 결과 화면 훅 (짧게)
- 오늘 시드로 플레이했을 때만: result-grid 아래 한 줄
  - 성공: `오늘의 승부 클리어! · 칭호 해금` `#9BFFE6`
  - 실패: `오늘의 목표까지 PERFECT 1회 부족` `#FFAB8C`

|---|---|---|
| Navy base | `#081329` / `#030913` | 배경 |
| Panel | `#0B1E35` → `#122B52` | 모달·카드 |
| Cream text | `#F7F3E8` | 본문 |
| Gold accent | `#FFE09A` / `#FFE3A1` | 강조·장착·1등 |

| Sky blue | `#96C2F7` / `#79AEFF` | eyebrow·링크 |
| Special purple | `#C3A4FF` / `#775CFF` | 마구·일일·CTA |
| Muted | `#AABED8` / `#7A8FA8` | 보조·잠금 |
| Success mint | `#9BFFE6` | 클리어·포커스링 |

### 타이포
- UI: `system-ui, -apple-system, 'Segoe UI', sans-serif` (기존 유지)
- 타이틀/브랜드: italic + weight 900~1000 · letter-spacing -1~-2
- Eyebrow: 9~12px · tracking 2px · `#96C2F7`
- 본문: 14~16px · `#C4CFE0` / `#F7F3E8`
- 칭호명: 14px bold · `#FFE2A1` (장착 시 동일)
- 숫자: `font-variant-numeric: tabular-nums`

### 아이콘 스펙
- 스트로크 아이콘 24×24 뷰포트, stroke 1.75, round join
- 도감 버튼: 방패 + 작은 별
- 칭호 기본 세트: 트로피(크림) / 불꽃(코랄) / 숫자3 뱃지(퍼플)
- 잠금: 자물쇠, `#7A8FA8`
- 신규 해금 점: 8px circle `#FF986E` on 도감 버튼

### 모션 (짧게)
- 패널 오픈: 기존 오버레이 페이드만 (과한 슬라이드 X)
- 장착 전환: 칩 텍스트 crossfade 150ms
- 해금 펄스: scale 1→1.03→1 / border glow 400ms 1회
- `prefers-reduced-motion: reduce` 시 펄스·크로스페이드 제거

### 구현 우선순위
1. A 칩 + B 도감 모달 (로컬 저장 장착 ID)
2. C-1 오늘 카드 + C-2 오늘 탭
3. 해금 연출·결과 훅
