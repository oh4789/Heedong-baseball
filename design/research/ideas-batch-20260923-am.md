## TOP1 — 투구 팁핑(몸짓 텔)

| 항목 | 내용 |
|---|---|
| ① 원칙 | 글러브 높이·벌어짐·셋 포지션으로 구종이 새는 실전 야구 패턴. 오디오/모양 텔레그래프와 다른 **몸짓** 축. |
| ② 출처 | https://thebaseballcodes.com/2021/01/27/the-complete-guide-to-tipping-pitches-in-baseball/ |
| ③ 희동이 적용점 | 희동이 보스에 야구 테마 직결. 불꽃 vs 일반을 셋업 포즈만으로 읽히게 해 VO·모양언어와 직교. |
| ④ 구체안 | (1) 불꽃: 셋 때 글러브 살짝 벌어지거나 높게 / 일반: 타이트·벨트 높이. (2) 초반엔 팁을 크게, 후반엔 미세하게. (3) 가끔 거짓 팁 1회(코어 규칙 아님). |
| 판정/규칙 변경 | **없음** (연출·텔레그래프만). 스윙/회피 판정식 불변. |

## TOP2 — Trauma² 카메라 펀치 + 짧은 FOV

| 항목 | 내용 |
|---|---|
| ① 원칙 | Trauma를 제곱해 흔들고 Perlin으로 감쇠. 히트스톱·햅틱과 **별 레이어**의 카메라 주스. |
| ② 출처 | https://boomiestudio.com/blog/game-juice-guide (2026-07) |
| ③ 희동이 적용점 | Perfect 손맛 강화. 모바일에서도 짧은 FOV/오프셋만으로 ‘맞은 감’ 상승. Perfect 히트스톱과 직교. |
| ④ 구체안 | (1) Perfect: Trauma ~0.5–0.6 + 0.05–0.1s FOV punch. (2) Good: Trauma ~0.25. (3) Miss·피격은 방향·색수차만 짧게. (4) 저사양·모션 민감 옵션에서 카메라만 끄기. |
| 판정/규칙 변경 | **없음** (연출만). |

## TOP3 — [제안] 비가시 타이밍창 DDA

| 항목 | 내용 |
|---|---|
| ① 원칙 | 최근 미스율로 스윙 판정창을 ±수%만 조용히 조절(히스테리시스·캡). Soft Heat(대기 시 투구 밀도)과 다른 축. |
| ② 출처 | https://en.wikipedia.org/wiki/Dynamic_game_difficulty_balancing · https://dev.to/unitysourcecode/building-a-tap-timing-hyper-casual-game-in-unity-the-engineering-behind-one-perfect-tap-24g7 |
| ③ 희동이 적용점 | 캐주얼 이탈↓, 숙련 보상 유지. UI에 노출하지 않음. |
| ④ 구체안 | (1) 최근 8–12구 Perfect/Miss로만, **이닝 경계에서만** 반영. (2) 상·하한 캡 + 한 방향 유지 최소 N구(히스테리시스). (3) UI/카피 절대 비노출. |
| 판정/규칙 변경 | **[제안]** — 판정 윈도우 수치를 조용히 조절하므로 코어 판정에 해당. **보류 유지.** |
