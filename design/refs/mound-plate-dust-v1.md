## 목표
투구 **릴리즈 때 마운드 흙먼지**와 공이 **플레이트를 지나간 뒤 지면 먼지**로 "세계가 반응한다"는 환경 잔향만 준다.
**판정·결과와 무관** — 매 투구 개수·모양·타이밍이 같다(구종·불꽃·결과 불문). **타이밍 힌트로 쓰일 수 없게** 설계.
**비주얼 전용 — 판정창·히트박스·점수·스침·투구 확률·engine 불변.**

근거: `design/research/ideas-batch-20260928-pm.md` ② (Swink environmental response · MoCap 2026-03 foot-notify dust · Wizus 2026-07) · Director 9/28 PM ②.

## 2. 고정 테이블 (보드와 같은 값)

```js
// i = 0..11 (마운드) / 0..5 (플레이트), d = i%2 ? +1 : -1
MOUND[i] = { x0: MX + d*(4 + (i>>1)*5), y0: MY + ((i*7)%5 - 2),
             vx: d*(10 + (i*5)%17), vy: -(10 + (i*3)%9),
             life: 360 + (i*37)%101, r0: 4 + (i%3)*0.6, grow: 2.6, peak: .20, g: 24, flat: 1.15 };
PLATE[i] = { x0: PX + d*(10 + (i>>1)*14), y0: PY + (i%2),
             vx: d*(14 + (i*7)%16), vy: -(4 + (i*3)%5),
             life: 280 + (i*29)%81, r0: 3.5, grow: 2.8, peak: .16, g: 18, flat: 1.6 };
// 위치: x = x0 + vx*t*(1 - .35*t/L),  y = y0 + vy*t + .5*g*t²
// 반경: r = r0 * (1 + (grow-1)*(1-(1-t/L)²))
// α:   t<80ms ? peak*t/80 : peak*(1-(t-80)/(L-80))^1.5
```

## 3. 타이밍 · 힌트가 아닌 이유

가장 빠른 공 기준 (fast 1.32s × stage scale 0.68 ≈ **898ms**, sy=290):

| 구간 | q (비행 진행도) | ms | 비고 |
|---|---|---|---|
| 릴리즈 · 마운드 먼지 시작 | 0 | 0 | 릴리즈 포즈 전환과 같은 프레임 |
| 마운드 먼지 최대 α | — | 80 | 릴리즈 시각 자체는 이미 포즈·공 등장으로 보임 → 새 정보 없음 |
| 마운드 먼지 종료 | — | ≤460 | |
| 스윙 가능 창 시작 (zone y 608 ± 48 → y 560) | 0.75 | 673 | 마운드 먼지 종료와 **≥213ms 간격** |
| 스윙 가능 창 끝 (y 656) | 1.017 | 913 | |
| 피격 판정 끝 (player y 650 ± 21 → y 671) | 1.06 | 953 | |
| **플레이트 먼지 시작** (y 715) | **1.18** | **1060** | 모든 판정 가능 구간 종료 **≥107ms 뒤** |
| 플레이트 먼지 종료 | — | ≤1420 | |
| 헛공/회피 결과 처리 (y>785) | 1.375 | 1235 | 먼지는 모든 공에서 나오므로 결과 정보 없음 |

- 느린 공(체인지업 2.0s·슬라이더 1.65s·early ×1.15)은 비율이 같아 간격이 더 넓어진다.
- 희원 공(sy 245)도 같은 공식 → q≈1.15, 창 종료 뒤.
- **힌트가 아닌 이유 4가지**: (1) 매 투구 개수·모양·타이밍 동일 → 구종·결과 정보 0. (2) 마운드 먼지는 이미 보이는 릴리즈 동작에 붙어 있고, 스윙 창 시작 전에 사라짐. (3) 플레이트 먼지는 스윙·피격 판정이 **끝난 뒤**에만 나옴. (4) 최대 α 0.16–0.20, 플래시·가산 없음 → 저대비.
- 타격된 공은 플레이트에 오지 않지만, 플레이트 먼지는 **예정 시각에 그대로 발생**(포수 미트 쪽 환경 잔향으로 해석). 결과로 먼지를 켜고 끄지 않는다(§8 결정 사항).

## 4. 레이어 순서 (아래 → 위)

```
1. 경기장 배경            ← 릴리즈 DoF 블러 대상 (pitch-release-dof-focus-v1)
2. 희동이 스프라이트 + 흙판 페이드 밴드(y 400–442)
3. ★ 마운드 먼지          ← 투수 레이어 · 샤프 · 블러 버퍼에 넣지 말 것
4. 텔레그래프 레인 (와인드업 중)
5. 회피 잔상 (타자 뒤)
6. ★ 플레이트 먼지        ← 지면층 · drawBatter() 직전 (타자 발·그림자 타원 아래)
7. 타자 (+ 발밑 그림자 타원)
8. 공 루프: 비행 트레일 → 공 그림자(지면) → 열왜곡(불꽃) → 공 + 시임
9. 귀환공·금빛 트레일 → effects(배트/헛스윙 먼지 3px 점) → juice → HUD
```

| 채널 | 관계 |
|---|---|
| 릴리즈 DoF 블러 | 마운드 먼지 수명 전체가 DoF ON 구간 안. **투수 레이어에 그려 샤프 유지**. 먼지를 배경 버퍼에 넣으면 이중 블러로 사라짐(보드 D 우측). 블러된 관중석이 평탄해져 퍼프가 오히려 잘 읽힘. 플레이트 먼지는 DoF가 꺼진 뒤(접촉 −80ms 이후) 발생 |
| 비행 트레일 | 공 경로(공중) vs 먼지(지면) · 트레일이 위 레이어 |
| 공 그림자 | 둘 다 지면이지만 그림자가 위 레이어. 플레이트 먼지 시점엔 공이 이미 플레이트 뒤 |
| 시임 · 열왜곡 | 공 표면·공 주변 — 공간 겹침 없음, 먼지는 항상 아래 |
| 배트/헛스윙 먼지 | 접촉점(공중, y≈608) vs 지면(y 728) · 시점도 다름 |

## 5. 배트 먼지와 구분 (코드 확인 결과)

refs에는 별도의 배트 접촉 먼지 스펙이 없다. 배트 근처 먼지는 `game.js`의 `spawnMissDust()`(헛스윙) 하나이며, `hit-juice-budget-v1` Miss 행을 구현한 것이다. 그 밖에 니어미스 코랄 연기(`spawnSmoke`, `#FF7A6E`)와 Perfect/Good 스파크가 있다.

| 항목 | 배트 먼지 `spawnMissDust` | 환경 먼지 (본안) |
|---|---|---|
| 색 | 크림 `#F5E6C8` | 샌드 탄 `#C8A27A` / `#B08A66` + 림 `#E3C9A0` |
| 모양 | `fillRect` **3×3px 네모 점** | **둥근 소프트 퍼프**(방사 그라데이션), 커지며 사라짐 |
| 움직임 | 위쪽 원뿔 ±43°, 12–40px/s로 튐 | 옆으로 흐름 10–30px/s, 약하게 떠올랐다 가라앉음 |
| 수명 | 50–80ms | 280–460ms |
| 위치 | 접촉점 `game.zone` (공중) | 투수 발밑 흙판 · 홈플레이트 지면 |

| 발생 | 헛스윙만 | 매 투구 |

→ 색(크림 vs 탄), 모양(네모 점 vs 퍼프), 속도·수명(빠르고 짧음 vs 느리고 김), 위치(공중 vs 지면) 4축이 모두 다르다.

## 7. 캔버스 구현 메모

1. **퍼프 스프라이트 1장**: 32×32 오프스크린에 방사 그라데이션(중심 α1 → 가장자리 0)을 1회 굽고, 입자마다 `drawImage(puff, x−rx, y−ry, 2rx, 2ry)` + `globalAlpha`. 윗면 림은 같은 크기의 `#E3C9A0` 스프라이트를 α×0.5로 y−r×0.3에 한 번 더 그림(선택).
2. **풀**: `ambientDust = []` (최대 40). 버스트는 `{kind:'mound'|'plate', t0, table}` 1개로 저장하고 입자 상태는 §2 공식으로 **그릴 때 계산**(업데이트 루프 비용 0, 난수 없음).
3. **트리거**: `processEvents`의 `e.type==='pitch'` 분기에서 `spawnMoundDust()`. 같은 시점에 공마다 `plateAt = visualTime + b.duration*(715−sy)/(650−sy)`를 예약 → 시각이 되면 `spawnPlateDust()`. 공이 이미 타격돼 사라졌어도 예약은 유지.
4. **그리기 위치**: `drawPitcher()` 직후 `drawMoundDust()` / `drawBatter()` 직전 `drawPlateDust()`. DoF 배경 오프스크린 경로가 들어오면 **그 버퍼 밖**에서 그릴 것.
5. **금지**: `Math.random`, 구종·결과·판정 분기, 가산 합성, `#FF3B3B`. 판정 함수·히트박스·점수와 연결 금지.
