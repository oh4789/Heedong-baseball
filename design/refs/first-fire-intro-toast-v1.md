# 첫 불꽃 등장 카피 토스트 · FIRST-FIRE INTRO TOAST v1

파일: `design/assets/first-fire-intro-toast-v1.png`

## 목표
플레이어 **첫 불꽃 마구** windup 직전 1회 강조 토스트. **비주얼·카피 코칭만**. 회피 규칙·판정·타이밍 윈도우·밸런스 변경 없음.  
근거: `flow-and-fullscreen-v1.md` — 「첫 불꽃 직전 1회 강조 토스트가 있으면 더 안전(카피만, 규칙 변경 X)」.

## 레이아웃
- 모바일 세로 **9:16** 시안(1080×1920). 토스트는 **풀 모달 아님** — 중앙 글래스 카드.
- 위치: **화면 중상단(mid-upper third)**, 타자 컨택트 존·하단 sticky CTA **위**. CTA SAFE 영역 미침범.
- 글래스 언어는 `title-unlock-toast-v1`과 동일계열이나, 림/아이콘을 **파이어코랄**로 구분(축하 골드/퍼플 금지).

## 카피 (고정)
1. 「불꽃 마구 등장!」 — 크림/화이트 볼드
2. 「손가락을 옆으로 밀어 회피」 — 크림 세컨더리 (+ 좌우 셰브론 제스처 힌트 선택)
3. 「이번만 안내」 — 뮤트 힌트

## 프로그래머용 크롭·익스포트
- 풀 시안: `assets/first-fire-intro-toast-v1.png` (플레이스먼트 참고)
- 토스트 카드(+상단 불꽃 아이콘): 약 **360×140 @2x → 720×280** PNG (**투명 배경** 권장)
  - 아이콘 overhang 포함 시 **720×340** 허용
- 세이프 센터: 480-wide 캔버스 기준 가로 중앙, Y ≈ 화면 높이의 22~28%
- 선택 시트: idle → pop → hold → fade 4프레임 가로 시트

## 팔레트
- BG `#081329`
- 크림 텍스트 `#F5E6C8`
- 파이어코랄 림 `#FF7A6E` / 딥파이어 `#FF5A2A`
- 앰버 하이라이트 `#FFAB88`
- 골드 코어(아이콘만, 절제) `#FFE09A`
- 민트 컨택트 존은 배경 참고용만 (`#9BFFE6`) — 토스트 림에 쓰지 않음
- **빨강 회피전용 큐 남용 금지** (코어 결정 보류). 코랄/앰버 경고 셰브론만.

## 타이밍 제안
- pop **~150ms** scale(0.88→1.0 + soft overshoot)
- hold **~1.4s**
- fade **~200ms**
- spawn: **첫 불꽃 windup에만 1회** (이후 런/세션 재표시 금지). 기존 텔레그래프 VFX와 병존 가능(토스트는 카피 레이어).
