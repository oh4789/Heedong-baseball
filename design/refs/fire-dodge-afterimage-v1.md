# 불꽃 회피 애프터이미지 · FIRE DODGE AFTERIMAGE v1

2026-09-28 문서 수정: 고스트 알파 순서(최신부터 0.45/0.30/0.18/0.10), 「회피!」 색 코랄로 정정 (코드 변경 없음)

파일: `design/assets/fire-dodge-afterimage-v1.png` (시안 보드 라벨 한글 · **1600×900**)

## 목표
불꽃 마구를 **드래그로 회피 성공한 순간**에만 타자 **고스트 잔상 3–5장**을 남겨 ‘빠져나감’을 읽히게 한다.  
기존 「회피!」 코랄 플로팅·fire-dodge-juice·air whizz 스트릭과 **채널·타이밍·위치 분리**한 **연출 확장**.  
**판정 박스·창·engine·점수·스침 규칙 불변**.

근거: `design/research/ideas-batch-20260924-pm.md` **TOP2** · Saltmire Godot afterimage (interval≈0.04s) · juice 스택(규칙 불변).

---

## 트리거

| 조건 | 애프터이미지 |
|------|--------------|
| **불꽃 회피 성공** 판정 프레임 | **ON** (activate → 150–220ms 후 deactivate) |
| 일반 드래그 (스윙/이동) | **OFF** |
| 일반구 니어미스 / 아슬아슬 | **OFF** |
| Miss / Perfect / Good 타격 | **OFF** (본안 범위 밖) |
| `prefers-reduced-motion` | **OFF** 또는 **고스트 1장**만 (아래 RM) |

노이즈 방지: 불꽃 성공 **이외**에는 잔상을 켜지 않는다.

## 고스트 파라미터

| 항목 | 값 |
|------|-----|
| 장수 | **3–5** (기본 4 · 저사양 3 · 풀 5) |
| 스냅샷 간격 | **≈40ms** |
| 총 수명 | **150–220ms** (권장 180ms) |
| 알파 램프 (최신→오래된) | **0.45 / 0.30 / 0.18 / 0.10** (+옵션 5장 **0.06**) |
| 틴트 | 연한 **민트/시안** (페일 시안 쪽 바이어스) |
| z-order | **타자 뒤** (고스트 < 라이브 타자) |
| 위치 | 타자 몸 실루엣 · 이동 반대쪽으로 살짝 밀림(드래그 벡터 잔상) |
| 금지색 | `#FF3B3B` **사용 금지** |

알파 순서 메모: 코드/Director 결정에 따라 타자에 가장 가까운 최신 고스트부터 **0.45 / 0.30 / 0.18 / 0.10**을 적용한다(5장일 때 가장 오래된 고스트 **0.06** 추가).

프로그래머 상수 초안:

```
AFTERIMAGE_ON_FIRE_DODGE_ONLY = true
AFTERIMAGE_GHOST_COUNT        = 4      // low-end: 3
AFTERIMAGE_INTERVAL_MS        = 40
AFTERIMAGE_LIFE_MS            = 180    // 150–220
AFTERIMAGE_ALPHAS             = [0.45, 0.30, 0.18, 0.10] // newest→oldest; optional 5th oldest: 0.06
AFTERIMAGE_TINT               = cyan/pale-mint
AFTERIMAGE_Z_BEHIND_BATTER    = true
JUDGMENT_UNCHANGED            = true
SCORE_UNCHANGED               = true
GRAZE_UNCHANGED               = true
```

## 통합 타임라인 · 시퀀싱 (회피 성공 = 0ms)

공기가 휘즈 시트(`air-whizz-passby-v1`)의 불꽃≈120ms 스트릭을 **최근접≈판정**에 맞추면, 잔상 피크를 **뒤로** 밀어 동시 피크를 피한다.

| ms | 「회피!」UI | fire-dodge-juice | 휘즈 스트릭 | **잔상(본안)** |
|----|-------------|------------------|-------------|----------------|
| **0** | 팝 스폰 | 스파크 ON | 최근접 시작 | 스냅샷 캡처 시작 |
| **0–30** | **팝 피크** | 스파크 피크 | **최근접 피크** | 캡처(아직 약) |
| **30–50** | 플로트↑ | 스파크→링 | 통과 시작 | G1 등장 |
| **40–80** | 플로트 | 링 확장 | 통과 | G1–G2 |
| **70–110** | 플로트 | 링 | 정착→종료 | G2–G3 |
| **80–150** | 플로트 | 페이드 시작 | (종료) | **몸 잔상 피크** |
| **150–220** | 플로트 | 페이드 | — | 페이드아웃 → OFF |
| **~700** | 플로트 종료 | juice 종료 | — | — |

**피크 분리 요약**
- 텍스트 팝: **0–30ms** (UI · 타자 위)
- juice 스파크: **0–50ms** (코랄/골드 · 타자 주변 파티클)
- 휘즈 최근접: **0–30ms** (민트 스트릭 · **공 경로**)
- 잔상 몸 피크: **80–150ms** (시안/페일 · **몸 · 타자 뒤**)

관련: `design/refs/fire-dodge-juice-v1.md` · `design/refs/air-whizz-passby-v1.md`  
(휘즈 원본 밴드: approach 0–40 / closest 40–70 / pass 70–110 / settle 110–150 · 불꽃≈120ms 강 민트)

## 채널 분리

| 채널 | 역할 | 색 | 위치 | 본안과의 관계 |
|------|------|----|------|---------------|
| 「회피!」 코랄 플로팅 | 성공 UI 라벨 | 코랄 `#FFAB88` | 타자 **위** UI | 유지 · 병행 |
| fire-dodge-juice | 보상 스파크·링 | 코랄/골드 + 옵션 민트 링 | 타자 주변 파티클 | 유지 · 병행 |
| air whizz 스트릭 | pass-by 공기 왜곡 | **민트** (강) | **공 경로** | 유지 · 병행 |
| **애프터이미지** | 몸 ‘빠져나감’ | **시안/페일** (민트보다 차갑게) | **몸 · 타자 뒤** | **본안** |

색: 잔상=시안·페일 / 휘즈=민트 / 텍스트=코랄(코드 `#FFAB88`, 위치·타이밍으로 구분).  
위치: 잔상=몸 뒤 / 스트릭=공 궤적 / 텍스트=위.  
→ 동시 재생 OK · 피크·레이어 충돌 없음.

## Reduced motion · 저사양

| 모드 | 동작 |
|------|------|
| `prefers-reduced-motion` | **OFF** **또는** 고스트 **1장**만 (α≈0.35 · 수명 ≤120ms) |
| 저사양 | 고스트 **3장** · 알파 최신→오래된 **0.45 / 0.30 / 0.18** · **프리틴트 실루엣 스프라이트 재사용** (런타임 틴트/셰이더 X) |
| 풀 | 4–5장 · 동일 실루엣 + 알파 램프 (4장: **0.45 / 0.30 / 0.18 / 0.10**, 5장: **0.45 / 0.30 / 0.18 / 0.10 / 0.06**, 최신→오래된) |

저사양 파이프: `ghost_sil_cyan@2x` 1장 재사용 × 3 인스턴스 (오프셋·알파만).
