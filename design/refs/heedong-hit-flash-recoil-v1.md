# 희동이 피격 플래시 + 미세 리코일 · v1

파일: `design/assets/heedong-hit-flash-recoil-v1.png` (시안 보드 라벨 한글)

## 목표
**맞은 쪽(희동이)** 수신 juice만. Trauma²(카메라)·히트스톱(시간)·배트/공 juice와 **다른 레이어**. **판정·점수·engine 수치 불변**.

## 등급별
| 등급 | 플래시 | 리코일 |
|------|--------|--------|
| **Perfect** | 실루엣만 **50–80ms** 화이트 플래시 | **1–3px** 뒤로 밀림 → 스프링 복귀 (둘 다) |
| **Good** | 플래시만 (Perfect보다 약해도 됨) | 약하거나 **없음** |
| **Miss** | 금지 | 금지 |
| **불꽃 회피 성공** | 금지 | 금지 (위협 레인과 혼선 방지) |

## 채널 분리
| 채널 | 소유 |
|------|------|
| Trauma² | 카메라 punch / FOV |
| 히트스톱 | 시간 프리즈 |
| 배트·공 juice | 공격 측 파티클·스미어·플래시 |
| **본 시트** | 희동이 **개체별** 실루엣 플래시 + 미세 리코일 |

- **공유 머티리얼 함정 금지** — 보스 인스턴스/스프라이트만 플래시. 전역 화이트아웃 금지.

## 프로그래머용
- 플래시: 희동이 스프라이트/실루엣에 additive white 또는 color multiply → 1, 50–80ms ease-out
- 리코일: local X(또는 투구 반대 방향) 1–3px · spring back ~120–180ms (배트 settle과 수치 비슷해도 **대상이 다름**)
- 앵커: 희동이 피벗(몸통 중심). 카메라/월드 흔들림과 합산하지 말 것
- reduced-motion: **리코일 OFF**, 플래시는 **짧은 스냅**(1–2f) 허용
- 크롭 참고: 보드 중앙 실루엣 프레임 256–512px
