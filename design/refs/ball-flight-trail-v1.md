# 공 비행 트레일 잔광 · v1 (ball-flight-trail-v1)

파일: `design/assets/ball-flight-trail-v1.png` (시안 보드 · 라벨 한글 · **1600×900** · `#FF3B3B` 0px 확인)

## 목표
비행 중인 공 **뒤쪽의 과거 위치**에 짧은 페이드 잔광을 남겨, 공 본체보다 먼저 **방향·속도**를 주변시로 읽히게 한다.
시임(공 텍스처) · 열왜곡(공 주변 공기) · 그림자(지면 깊이) · 휘즈(통과 순간)와 **직교인 "과거 위치" 채널**.
**비주얼 전용 — 판정창·히트박스·점수·스침 규칙·투구 확률·engine.js 불변.**

## 1. 파라미터 비교표 (일반 vs 불꽃 vs Perfect 금빛)

| 항목 | 일반구 트레일 (본안) | 불꽃구 트레일 (본안) | Perfect 금빛 트레일 (기존, 비교용) |
|---|---|---|---|
| 적용 | 직구·체인지업·슬라이더·희원 공 (쉬운 구 실루엣 ON 시 제외) | `type==='fire'` 비행 중 | Perfect 타격 후 귀환 공 (`game.returns[].perfect`) |
| 시점 | 비행 중 (릴리즈 후 `b.t≥0`) | 비행 중 | 타격 **+75ms**부터 귀환 끝까지 |
| 방향 | 투수→타자 (아래쪽) | 투수→타자 | 타자→희동이 (위쪽) |
| 색 (외곽 / 코어) | `#F7F3E8` / `#FFFFFF` | `#FF986E` / `#FFC48A` | `#FFE09A`·`#FFD25B` / `#FFF2A5` + 보라 별 `#C3A4FF` |
| 폭 (머리→꼬리) | **10 → 6px** 테이퍼 (범위 6–12) | **12 → 7px** (+2px) | 외곽 9–16px · 코어 6–10px 균일 리본 |
| 표본 수 | **5** (4–6 허용) | **5** | 연속 곡선(표본 없음) |
| 표본 간격 | 22ms | 22ms | — |
| 수명 | **110ms** (80–120 허용) | **110ms** | 귀환 전체(≈0.4s+) |
| α (머리→꼬리) | 0.50 → 0.04 | 0.55 → 0.05 | 0.55–0.93 유지 |
| 글로우 (`shadowBlur`) | **0** | **0** | 14–32 |
| 형태 | 끊김 느낌의 짧은 테이퍼 잔광 | 동일 + 헤이즈 컷아웃 쐐기 안에서만 | 흔들리는 곡선 리본 + 별 3–7개 |
| 합성 | `lighter` (가산) 1회 | `lighter` 1회 | source-over + 글로우 |
| 판정 시 | **≤60ms** 소멸 | **≤60ms** 소멸 | 유지 |

**구분 3요소**: 색(크림/오렌지 vs 금+보라) · 굵기(≤12px, 글로우 0 vs 16px+글로우) · 타이밍(판정 전 110ms 창 vs 판정 +75ms 이후). 트레일은 0–60ms에 끝나고 금빛은 +75ms에 시작 → **시간 겹침 0**.

## 2. 표본별 폭·α 감쇠

`age_k = k × 22ms`, 꼬리 끝(110ms)은 폭 0·α 0으로 수렴.

| 표본 | age | 일반 폭 | 일반 α | 불꽃 폭 | 불꽃 α |
|---|---|---|---|---|---|
| s0 (공 위치) | 0ms | 10px | 0.50 | 12px | 0.55 |
| s1 | 22ms | 9px | 0.35 | 11px | 0.39 |
| s2 | 44ms | 8px | 0.22 | 10px | 0.25 |
| s3 | 66ms | 7px | 0.11 | 9px | 0.13 |
| s4 | 88ms | 6px | 0.04 | 7px | 0.05 |
| 꼬리 | 110ms | →0 | 0 | →0 | 0 |

- α 곡선 ≈ `A0 × (1 − age/110)^1.6`, 폭은 표본 간 선형.
- 코어 선: 폭 × 0.45, α × 1.25(≤1), 흰/연앰버 — 중심 방향성만 또렷하게.
- **근접 감쇠**: `approach01 > 0.85`(타자·배트 근처)면 전체 α × **0.7** → 배트/타자 가림 최소화.
- (선택) 깊이 스케일 `lerp(0.85, 1.0, approach01)` — 단, 일반 6–12px / 불꽃 7–13px로 클램프.

## 3. 타이밍

| 단계 | 규칙 |
|---|---|
| 스폰 | 릴리즈 후 첫 비행 프레임(`b.t ≥ 0`)부터 매 렌더 프레임 위치 기록. 첫 110ms는 버퍼가 차는 만큼만 그림(자연스러운 성장). |
| 유지 | 최근 110ms 창만 렌더 (매 프레임 갱신). |
| 소멸 트리거 | 공 판정 확정 프레임 — `perfect` / `hit` / `damage`(피격) / `vulnerable`(불꽃 회피 성공) / 공 이탈(`y>785` resolve) 중 **먼저 온 이벤트 1회**. |
| 소멸 | 판정 프레임에서 표본 위치 **고정**(샘플링 중단) → `α × (1 − t/60)²` ease-out → **60ms에 0**, 스냅샷 삭제. |
| 헛스윙 | 공은 계속 날아가므로 트레일 유지 → 이탈 resolve 시 60ms 소멸. |

### 인접 채널과의 시간 관계 (판정 = 0ms)
| 채널 | 시간 | 관계 |
|---|---|---|
| 비행 트레일 | ~0ms, 소멸 0–60ms | 본안 |
| 열왜곡 후광 | ~0ms, 소멸 0–80ms | 공간 분리(쐐기 컷아웃)로 동시 재생 OK |
| 휘즈 스트릭 | 0–110ms (피크 40–70) | 40–60ms 구간 트레일 α ≤ 0.33×로 이미 약함. 민트 vs 크림/오렌지 색 분리 |
| Perfect 금빛 | +75ms~ | **겹침 0** |
| 회피 잔상 | 40–200ms (피크 80–150), 타자 뒤 | 겹침 없음(위치: 몸 vs 공 경로) |

## 4. 레이어 순서 (아래 → 위)

```
배경 → 회피 잔상(타자 뒤) → 타자 → [공 루프]
  그림자(지면)  →  열왜곡 링(쐐기 컷아웃 적용)  →  ★비행 트레일(lighter, 쐐기 클립)
  →  공 본체 + 시임 텔  →  불꽃 착지 오벌/! 배지  →  휘즈 스트릭 / UI
```

- **시임**: 공 스프라이트가 트레일 위에 그려지므로 공 원 내부(r)에는 트레일이 보이지 않음. 추가로 트레일 클립 시작 반경 `≥ r × 0.95`.
- **그림자**: 지면 평면 — 트레일은 공 좌표 경로만 따르므로 공간 분리. 그림자 위에 트레일을 그리지 말 것(그림자 먼저).
- **열왜곡 (불꽃, 5d9dff3)**: 헤이즈 환형 외곽 반경 = `r + HAZE_ZONE_PX×0.55`(=r+33px), 반면 트레일 길이는 속도×110ms ≈ 30–55px → **그냥 그리면 헤이즈 안에 완전히 들어가 겹친다.** 해결: 진행 반대 방향 **±22° 쐐기 = 트레일 레인**.
  - 헤이즈: 환형 클립에서 쐐기를 빼기(`evenodd` 또는 쐐기 부채꼴을 반대 방향으로 path 추가).
  - 트레일: 쐐기 부채꼴(반경 r×0.95 ~ r+80px)로 클립.
  - → 두 채널의 **픽셀 겹침 0**. 쐐기 경계 4° 소프트 엣지 권장.
- **휘즈 스트릭**: 통과 순간 옆선 — 트레일은 뒤쪽 잔광만. 동일 프레임에 공존해도 색·위치 분리.
- **기존 정적 모션선**(game.js 공 루프의 `lineTo` 1줄: 일반 4px `#fff1cc60`, 불꽃 14px `#FF5A2A66`)과 **불꽃 잔불 점 5개**(공 뒤 20–64px)는 트레일 레인과 겹치므로 **트레일 ON 시 OFF**(대체). 쉬운 구 실루엣 민트 속삭임 선은 그대로 유지(그 모드에선 본 트레일 OFF).

## 6. 캔버스 구현 메모

```js
// visual only — engine/ball object 불변 (WeakMap에 보관)
const TRAIL_LIFE_MS=110, TRAIL_SAMPLES=5, TRAIL_FADE_MS=60, TRAIL_WEDGE_DEG=22;
const TRAIL_NORMAL={w0:10,w1:6,a0:.50,edge:'#F7F3E8',core:'#FFFFFF'};
const TRAIL_FIRE  ={w0:12,w1:7,a0:.55,edge:'#FF986E',core:'#FFC48A'};
const ballTrails=new WeakMap();   // b -> {buf:Float32Array(3*12), head, n}
const trailFades=[];               // {pts, fire, ageMs}
```

1. **링 버퍼**: 공마다 `Float32Array(12×3)` (x, y, visualTimeMs). 렌더마다 push, 110ms+1 프레임보다 오래된 항목은 덮어씀. 60fps 기준 7–8개, 30fps 폴백 4개로도 보간 가능.
2. **표본 보간**: `age_k = k×22ms`마다 버퍼에서 선형 보간 → 5점 + 꼬리점. 프레임레이트와 무관한 모양(저fps에서 끊김 방지).
3. **그리기**: 표본 좌우 법선 오프셋으로 **테이퍼 폴리곤 1개** 생성 → 머리→꼬리 `createLinearGradient`(α 감쇠)로 fill 1회 + 코어 폴리곤 fill 1회. 세그먼트별 round-cap stroke는 `lighter`에서 이음매가 밝게 뭉치므로 비권장.
4. **합성**: `ctx.save(); ctx.globalCompositeOperation='lighter'; …; ctx.restore();` — 가산은 이 블록 안에서만.
5. **불꽃 클립**: 속도 벡터 `v=(pos−prev)`의 반대 방향 ±22° 부채꼴 `ctx.arc(x,y,r+80,back−w,back+w); ctx.arc(x,y,r*.95,back+w,back−w,true)`로 clip. `drawFireHeatHazeHalo`의 환형 clip에 같은 쐐기를 역으로 추가.
6. **소멸**: 판정 이벤트 핸들러(`beginFireHazeFade()`를 부르는 곳과 같은 지점 + perfect/hit + 이탈)에서 `trailFades.push(snapshot)`; `updateTrailFades(dt)`에서 60ms 후 제거.
7. **비용**: 공당 fill 2회 + (불꽃) clip 1회. `getImageData`·`shadowBlur` 없음.
8. **금지**: 트레일 파라미터를 판정 함수·히트박스·점수·스침·투구 확률에 연결 금지. `#FF3B3B` 사용 금지.

## 8. 제약 재확인
- 판정창·히트박스·점수·스침 규칙·투구 확률·engine **불변** (비행 VFX만).
