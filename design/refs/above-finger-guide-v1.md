# 손가락 위 판정·궤도 가이드 v1

파일: `design/screens/above-finger-guide-v1.png`

## 목표
드래그 중 엄지에 가리지 않도록 **접점 링·위험 궤도**를 손가락 **위쪽**에 표시. **판정값 불변 · 비주얼만.**

## 레이어
1. **접점 링** (민트 `#9BFFE6`) — 공·배트 접촉 예상 위치. 터치점이 아님.
2. **궤도 아크** (금 `#FFE09A`) — 위험/예상 궤적 점선.
3. **칩 라벨** — `접점` · `궤도` (작은 칩, 엄지 위).

## 배치
- Y: 엄지 끝보다 **+48~80px** 위 (safe above-finger band)
- X: 드래그 중심에 맞춤, 화면 가장자리 8px inset
- 하단 드래그 입력 영역과 겹치지 않음

## 타이밍
- show: 드래그 시작 즉시
- update: 드래그 중 매 프레임 접점/궤도 갱신
- hide: 릴리즈 또는 스윙 판정 직후 120ms fade

## 금지
- 판정 윈도우·히트박스·타이밍 수치 변경 금지
- 접점 링을 터치점(손가락)에 붙이지 말 것
- 불꽃 텔레그래프 코랄과 채널 혼동 금지 (접점=민트, 궤도=금)
