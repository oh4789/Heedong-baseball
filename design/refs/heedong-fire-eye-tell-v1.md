# 희동이 불꽃 눈빛 텔 · v1

파일: `design/assets/heedong-fire-eye-tell-v1.png` (시안 보드 라벨 한글 · 1600×900)

## 목표
불꽃 직전, 투수 **얼굴·눈선·표정**으로 ‘더 세고 어려운 공’ 기대를 짧게 만든다.  
**불꽃 전용** · 와인드업 말단만 · **판정 박스·창·engine·점수·구종 확률 불변**.  
글러브 티핑 · 시임/스핀 텔 · 불꽃 VO와 **직교인 얼굴 채널**.

근거: `design/research/ideas-batch-20260924-am.md` TOP3 · Cheshin et al. (Pitching Emotions; anger→더 빠르고 어려운 공 기대).

## 타이밍 · 와인드업 말단 창

| 구간 | ms (릴리즈=0) | 눈빛 | 비고 |
|------|---------------|------|------|
| 와인드업 전기~중기 | < −250 | **OFF** (측면/흐림) | 일반·불꽃 동일 베이스 |
| **눈빛 텔 창** | **−250 ~ 0** (창 길이 **120–250ms**) | **ON (불꽃만)** | 시선 카메라 고정 + 미간 **또는** 하이라이트 1펄스 |
| 릴리즈 직후~비행 | ≥ 0 | **OFF** | 시임 텔(80–200ms)과 시점 분리 |

- 권장 창 길이: **≈185ms** (120–250 중앙). `EYE_TELL_MS`로 클램프.
- 창은 **반드시 릴리즈에서 종료**. 비행 중 눈빛 유지 금지.
- reduced-motion: 하이라이트 펄스 → 1프레임 스냅(≈16ms) 또는 미간만.

## A vs B 규칙

| | **A 일반구** | **B 불꽃구** |
|--|-------------|-------------|
| 시선 | **측면 / 흐림** (카메라 비고정) | **타자·카메라 LOCK** |
| 미간 | 이완 | **미세 찌푸림** (옵션) |
| 눈 하이라이트 | 없음 | **1펄스만** (옵션 · 미간과 택1 또는 동시) |
| 눈빛 플래그 | OFF | **ON** (창 구간만) |
| 학습 | 베이스라인 | A와 **대비**로 읽힘 |

구현 최소셋: **시선 LOCK만**으로도 충분. 미간·하이라이트는 가독 보조.

## HARD — no fake

| 규칙 | 내용 |
|------|------|
| **눈빛 ON → 반드시 불꽃** | 텔을 켠 투구는 구종이 불꽃이어야 함. 거짓말·미끼·페이크아웃 **금지**. |
| 불꽃 ≠ 눈빛 필수 | 불꽃이어도 눈빛을 끌 수는 있음(옵션 오프·저자극). 단, **켠 뒤에는 거짓말 불가**. |
| 일반구 | 동일 와인드업 구간에도 눈빛 **OFF** 유지. |

페이크아웃·aim-lock 미끼불꽃·Soft Heat와 **겹치지 말 것** (ideas HARD 제외 목록).

## 저해상도 · 눈 스프라이트 2프레임

셰이더·블렌드셰이프 **불필요**. face crop 눈만 스왑:

| 스프라이트 | 내용 | 권장 사이즈 |
|------------|------|-------------|
| `heedong_eye_soft@2x` | 측면/흐림 · 미간 이완 | **128×128** (@2x) / 64×64 (@1x) |
| `heedong_eye_lock@2x` | 카메라 고정 + (베이크) 하이라이트·미간 | **128×128** (@2x) / 64×64 (@1x) |

- 불꽃 + 텔 창: `soft` → `lock` 1회 스왑 (하이라이트는 스프라이트에 베이크하거나 1프레임 오버레이).
- 그 외: `soft` 고정.
- 전신 키네마틱·Takamido급 표정 리그 **불필요**.

## 직교성 (채널 분리)

| 채널 | 소유 | 본 시트와의 관계 |
|------|------|------------------|
| 티핑 | 몸짓(글러브 높이/플레어) | **직교** — 몸; 본 시트는 **얼굴** |
| 시임/스핀 | 공 텍스처 · 릴리즈 후 80–200ms | **직교** — 비행 초반; 본 시트는 **와인드업 말** |
| 불꽃 VO | 투구 전 오디오 텔 | **직교** — 소리; 본 시트는 **비주얼** |
| 모양언어 / 공 그림자 | 레인 UI · 깊이 | **직교** |
| **본 시트** | **눈빛·시선·표정** | 릴리즈 직전 얼굴 텔 |

판정 함수·히트박스·구종 확률·점수식에 눈빛 파라미터 **넣지 말 것**.

```

EYE_TELL_WINDOW_MAX_MS = 250

EYE_TELL_ONLY_FIRE     = true  // HARD: ON이면 구종=불꽃 강제 정합
EYE_TELL_FAKE_ALLOWED  = false
EYE_SPRITE_SOFT        = "heedong_eye_soft"
```
