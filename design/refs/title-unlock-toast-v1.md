# 칭호 해금 토스트 · TITLE UNLOCK TOAST v1

파일: `design/assets/title-unlock-toast-v1.png`

## 목표
클리어 런에서 **새 칭호 해금**이 있을 때 결과 화면 위 축하 토스트. **비주얼만**. 해금 규칙·판정·칭호 로직 변경 없음.

## 레이아웃
- 모바일 세로(9:16) 시안. 토스트는 **풀 모달 아님** — 중앙 글래스 카드.
- 결과 sticky CTA(「한 판 더」) **위**에 띄움. CTA는 가리지 않되 약하게 보이게 유지.

## 프로그래머용 크롭·익스포트
- 풀 토스트 카드: 약 **360×160 @2x → 720×320** PNG(투명 배경 권장)
- 세이프 센터: 480-wide 캔버스 기준 중앙 크롭(시안 전체 1080×1920 중 카드 영역만)
- 선택 시트: idle → pop → hold → fade 4프레임 가로 시트

## 팔레트
- BG `#081329`
- 크림 텍스트 `#F5E6C8` (「칭호 해금!」)
- 칭호명 골드 `#FFE09A` (「일일 타자」)
- 퍼플 림 글로우 `#C3A4FF`
- 코랄 액센트는 CTA 잔상용으로만 절제 (`#FF7A6E`)

## 타이밍 제안
- pop **120ms** scale(0.86→1.0 + soft overshoot)
- hold **1.2s**
- fade **200ms**
- **새 unlock note가 있을 때만** spawn (기존 해금 재표시 금지)
